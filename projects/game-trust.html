Game_trust

CLIENT DELIVERED

A full secondary marketplace platform for in-game assets — trusted by a paying client.

The Problem

Trading in-game assets (diamonds, items) is common in multiplayer games, but the process is entirely manual — Facebook groups, DM negotiations, and screenshot-based verification. This creates trust issues, no transaction records, and makes it impossible for the middleman to track profit and inventory.

The client needed a structured platform that acts as a trusted middleman: buying from sellers at a lower price, selling to buyers at a higher price, with verified transactions and financial tracking.

What I Built

A complete marketplace platform with two separate transaction flows and role-based access control.

  • ✓ Buy Flow: Admin lists diamonds for sale, buyers create orders, upload payment proof, receive merchant screenshots
  • ✓ Sell Flow: Sellers submit offers with inventory screenshots, admin negotiates via chat, verifies merchant screenshots with Player ID tracking
  • ✓ Multi-role access: Buyer, Seller, and Admin dashboards with different permissions
  • ✓ Real-time chat per transaction for price negotiation and instructions
  • ✓ Financial dashboard: daily/monthly revenue, expenses, and profit tracking
  • ✓ Voucher system, rating system, and comprehensive admin tools

The Result

Successfully delivered to a paying client and used in production. This was originally built in Laravel (v1), then re-architected in Next.js 15 (v2) with improved performance and developer experience.

This is the most business-complex project in the portfolio — real financial workflows, role-based permissions, and the kind of logic that can’t be generated by an AI prompt alone.
