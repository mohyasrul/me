Jokskuy

FULL SYSTEM

Complete client and order management platform for an educational service operation.

The Problem

An educational service operation managed client orders through scattered WhatsApp chats, manual Google Sheets — creating lost orders, unclear payment status, and no delivery tracking.

What I Built

A complete management system handling the full lifecycle of service orders.

  • ✓Client-side: submit requests, real-time chat, upload payment proof, track status
  • ✓Operator-side: manage orders, chat with clients, verify payments
  • ✓Admin-side: full oversight, financial reporting, user management
  • ✓Real-time chat between all parties
  • ✓Payment proof verification workflow

The Result

A complete, production-ready system replacing scattered WhatsApp coordination with a structured platform. Built with React 19, Supabase, and TanStack Query.

React 19 Vite Supabase TanStack Query Tailwind CSS
