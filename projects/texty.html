Texty

LIVE

The pragmatic text expander for people who write the same things every day.

Chrome Web Store Marketing Site

The Problem

Freelancers, customer support teams, and power users spend hours every week typing the same messages over and over — price quotes, FAQ answers, intro messages, payment instructions.

Existing solutions were either too complex (full automation platforms), too limited (basic OS-level shortcuts), or too expensive for solo operators. There was no simple, fast text expander that just works in the browser.

What I Built

Texty is a Chrome Extension that lets users define text shortcuts. Type ;;price in any text field and it instantly expands into a full, professional reply.

  • ✓ Full Manifest V3 extension with content scripts + service worker architecture
  • ✓ Inline search with fuzzy matching, custom prefixes (;;), and undo support
  • ✓ Complete marketing site with license key system (LemonSqueezy + Supabase)
  • ✓ Built with Plasmo framework for faster development and better DX
  • ✓ Import/export shortcuts, variable placeholders for dynamic content

The Result

Texty is published and live on the Chrome Web Store. It’s the only project in the portfolio that’s a real, packaged product anyone can install right now.

This project proves I can ship end-to-end: browser extension development, payment integration, marketing site, and license management — all built and deployed solo.
